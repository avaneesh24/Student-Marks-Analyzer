# Student Marks Analyser

A beginner-friendly Python project that analyses marks for five subjects.

## Features

- Takes marks as user input
- Validates marks between 0 and 100
- Handles invalid numeric input using exception handling
- Calculates total marks
- Calculates average marks
- Finds highest and lowest marks
- Assigns a grade based on total marks
- Displays pass/fail status

## Concepts Used

- Variables
- User input
- Type conversion
- Conditionals
- Loops
- Exception handling
- Built-in functions such as max() and min()

## How to Run

Run the Python file using:

python student_marks_analyser.py

## What I Learned
This project helped me practice applying basic Python concepts together in a complete program, especially loops, conditionals and exception handling.
